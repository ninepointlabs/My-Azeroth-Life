Addons

Free, open-source addons for WoW Forever, from the publishers of this paper.

Every addon below is free and open source, made by Nine Point Labs for World of Warcraft: Forever. On Linux, each one with an install line goes in with a single OmaForge command; anywhere else, take the latest release from GitHub.

Class Companions

  • Priest companion · Holy, Discipline, Shadow

    Andric’s Addon

    What to cast, wear, quest and train, in one window. A Fortitude button: one press, one cast.

    /andric (or /priest)

    omaforge install -c forever github:ninepointlabs/andrics-addon

    andricsaddon.myazerothlife.com · GitHub · Latest release

  • Mage companion · Arcane, Fire, Frost

    Parzelle’s Addon

    What to cast, wear, quest, train and where to teleport. Buttons for water, food, mana gem and Arcane Intellect.

    /parzelle (or /mage)

    omaforge install -c forever github:ninepointlabs/parzelles-addon

    parzelles-addon.myazerothlife.com · GitHub · Latest release

  • Paladin companion · Holy, Protection, Retribution

    Tristan’s Addon

    A Paladin companion with a Battle (PvP) section, and dual spec from day one.

    /tristan (or /paladin)

    omaforge install -c forever github:ninepointlabs/tristans-addon

    GitHub · Latest release

  • Shaman companion · Elemental, Enhancement, Restoration

    Tazu’s Addon

    A Shaman companion, with dual spec from day one.

    /tazu (or /shaman)

    omaforge install -c forever github:ninepointlabs/tazus-addon

    GitHub · Latest release

  • Rogue companion · every race, both factions

    Forever Rogue

    Pick Pocket log, junkboxes and Lockpicking, poisons, rotation, gear, leveling, gold and PvP.

    /frogue
    /frogue pins toggles minimap pins

    omaforge install -c forever github:ninepointlabs/forever-rogue

    GitHub · Latest release

Other Forever Addons

  • A watch list, for both factions

    The Terminal List

    A personal watch list for players who crossed you: a red crosshair on nameplates, target frame, tooltip and chat. Open-world PvP killers can be added automatically.

    /tlist

    omaforge install -c forever github:ninepointlabs/the-terminal-list

    ttl.myazerothlife.com · GitHub · Latest release

  • An adventure recorder

    StoryTracker

    Records Forever adventures (quests, combat, loot, sessions, optional auto-screenshots) so they can be written up as stories for this paper.

    /storytracker

    GitHub · Latest release

    Playing Retail? See StoryTracker (Retail), same /storytracker.
